# Objetivos

Meu objetivo em MAC0214 é me preparar para a Maratona de Programação, focando na resolução de problemas e na participação em competições. Meu plano de estudos envolve a prática regular em juízes online, como o Codeforces e AtCoder, buscando aumentar minha familiaridade com diferentes estilos de problemas e níveis de dificuldade. Além disso, pretendo participar ativamente dos treinos presenciais organizados pelo MaratonUSP, que ocorrem no CEC toda sexta-feira às 14h às 17h, para ter um contato mais direto com outros competidores e simular o ambiente de competição.

Meu principal objetivo com essa preparação é garantir uma vaga para as fases regionais e, com isso, ser mais competitivo em relação aos meus colegas. Como objetivo secundário, busco melhorar minha performance em competições online frequentes, como as do Codeforces e AtCoder, para solidificar minha base de resolução de problemas.

Acredito que o conhecimento adquirido nessa prática é útil não só a programação competitiva como a várias disciplinas do curso, como Estruturas de Dados e futuramente Desafios de Programção Avançados.Para mensurar meu progresso semanalmente, pretendo manter um registro das questões resolvidas, dos contests e das resolvidas em upsolving. Para isso, utilizarei uma planilha de acompanhamento e manterei um repositório público no GitHub com minhas soluções e anotações, que servirá como um diário do meu aprendizado.
